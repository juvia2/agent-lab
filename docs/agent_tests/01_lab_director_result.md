### 요청서

| 항목 | 내용 |
|------|------|
| **연구 질문** | 한국어 주격 관계절(SRC)과 대격 관계절(ORC)에서 LLM의 surprisal 패턴이 인간의 읽기시간 비대칭과 일치하는가? |
| **가설** | H1: LLM에서도 ORC 동사 영역의 surprisal이 SRC보다 높다 (인간 RT 패턴과 일치) / H0: 차이 없음 |
| **독립변인** | 관계절 유형 (주격 vs 대격) — 2수준 |
| **종속변인** | 토큰/어절 단위 surprisal (bits) |
| **설계** | within-item, 조건당 20문항, Latin square 2목록 |
| **모델** | 로컬 실행 가능 모델 (7B급, LM 연구원 추천 대기) |
| **비교 대상** | 기존 한국어 읽기시간 데이터 (인지과학 연구원 확인 예정) |

### 확인 사항 🔍
1. "인간의 읽기시간 패턴과 일치" → 기존 논문의 패턴(ORC > SRC 난이도)과 방향 비교로 이해했습니다. 실제 인간 RT 데이터를 직접 수집하지는 않고, 선행연구 패턴과 비교하는 것으로 진행할까요?
2. 조건당 20문항 → 관심 문항 40개 + 필러 40개 (1:1 비율) 정도로 잡겠습니다.
3. 모델 1개로 할지, 크기별 비교(예: 7B vs 13B)도 포함할지 확인 부탁드려요.
