### 2. 언어학 전문가 (28/30) ✅
**강점**
- SRC/ORC 구조를 공백(gap) 위치 기반으로 정확히 정의
- 처리 비대칭에 대해 4개 이론(DLT, Surprisal, Cue-based, Constraint-based)의 **방향이 다른** 예측 제시
- 교란변인 8개 체계적 열거: 어휘 빈도, 문장 길이, plausibility, 유생성, 관계절 동사 빈도, 주절 동사 통제, 영형 주어, 토크나이저 경계
- 예시 자극 3쌍 — 한국어 관계절 고유 이슈(핵어 후치, 관계대명사 부재) 반영
- "한국어에서는 SRC가 오히려 어려울 수 있다"는 유형론적 경고

**개선 필요**
- 필러 문항 예시 부재
- 세종 코퍼스 빈도 기반 어휘 통제의 구체적 수치 미제시

### 3. 인지·뇌과학 연구원 (29/30) ✅
**강점**
- Surprisal Theory 기반 연결 가설을 Marr의 계산 수준에 명확히 위치시킴
- **Kwon et al. (2010)의 반대 패턴** (한국어에서 SRC > ORC 가능성) 경고 — 핵심 도메인 지식
- 혼합효과모델 수식 제시: `surprisal ~ rc_type * region + (1+rc_type|item)`
- △LogLik 기반 모델 비교 방법 구체적 제안
- 해석 한계 4원칙 (과잉 인지화, Marr 수준, 대안 설명, 일반화 제한) 모두 적용
- 인간 데이터 참조: SPR, eye-tracking 데이터셋 제안

**개선 필요**
- 검정력 분석(power analysis) 기반 문항 수 적절성 평가 미포함

### 4. 언어모델 연구원 (28/30) ✅
**강점**
- 3단계 모델 구성: EXAONE 3.0 7.8B(한국어 특화) + Qwen 2.5 7B(다국어) + LLaMA 3.1 8B(대조군)
- Masked LM 비권장 사유를 이론적으로 설명 (PLL 근사의 한계)
- subword→어절 합산의 수학적 근거: 조건부 확률의 연쇄법칙 → log의 합
- 맥북 메모리별 양자화 옵션 표 (16GB/32GB/64GB)
- 토크나이저 효과를 가장 중요한 주의사항으로 경고
- 리스크 4건 + 대응 방안

**개선 필요**
- 실제 벤치마크 수치(한국어 perplexity 등) 인용 없음
- Ollama에서 특정 모델의 GGUF 미지원 가능성 미검토

### 8. 검증 테스트 담당 (30/30) ✅
**강점**
- **과잉 일반화 3건 정확히 포착**:
  - "LLM이 이해한다" → "유사한 패턴을 보였다"
  - "인간과 일치한다" → "같은 방향의 비대칭을 보였다"
  - "잘 학습했다" → "학습 데이터의 분포를 반영할 가능성"
- **Cohen's d 역산 불일치 발견**: 보고된 SE에서 역산한 SD로 d를 재계산하면 0.83이 아닌 ~1.17 → 원자료 확인 필요 지적
- **다중비교 보정 누락 적발**: 4개 영역 각각 t-검정 → Bonferroni/Holm 보정 필요, head_noun p=.047 → 보정 후 비유의 가능성
- 어절 경계 오류 2건 → 전체 수치 신뢰성 훼손으로 심각도 높음 판정
- 분석 방법 계획 불일치 가능성 (LMM 계획 → 실제 t-검정)

**개선 필요**
- 없음 (만점)

## 종합 판정

### 강점
1. **도메인 특화**: 일반적인 NLP 지식이 아닌 **언어인지과학** 고유 지식 (garden-path, surprisal theory, DLT, 한국어 관계절 비대칭) 적절 활용
2. **한국어 특수성**: 영어 중심 이론의 한국어 적용 한계를 여러 에이전트가 독립적으로 경고
3. **견제 구조**: 보고↔검증, 해석↔검증 간 이중 안전장치 작동 확인
4. **형식 준수**: 각 에이전트가 지식 프로파일의 출력 형식을 정확히 따름

### 개선 과제
1. **백엔드 개발자**: MPS fallback 로직 강화 + 체크포인트 재개 시 중복 방지
2. **연구실장**: 토큰 예산 추정 + 실험 히스토리 검색 루틴 추가
3. **언어학 전문가**: 필러 문항 예시, 코퍼스 빈도 수치 포함
4. **인지과학 연구원**: 문항 수 적절성(검정력 분석) 루틴 추가

### 실가동 준비도
- **시스템 프롬프트 품질**: ✅ 실가동 가능 수준
- **에이전트 간 협업**: ✅ 충돌 감지·수치 견제·해석 범위 제어 작동
- **코드 파이프라인**: ✅ 3개 스크립트 구현 + 실행 검증 완료
