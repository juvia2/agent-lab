# 언어학 전문가 테스트 결과

## 테스트 입력
자문 요청: 한국어 주격/대격 관계절 LLM surprisal 실험 — 구조적 차이, 자극 설계, 교란변인

## 언어학 자문

### 현상 정의

한국어 관계절(relative clause)은 핵어명사(head noun)가 관계절 뒤에 오는 핵어 후치(head-final) 구조이다. 관계절 내에서 핵어명사가 차지했던 원래 위치에 공백(gap)이 남으며, 이 공백의 문법적 기능에 따라 주격 관계절(subject RC)과 대격 관계절(object RC)로 구분된다.

**주격 관계절(SRC)**: 핵어명사가 관계절 내에서 주어 역할 → 공백이 주어 위치
- 구조: [ _i 목적어를 V-ㄴ ] 핵어명사_i
- 예: [ _i 논문을 쓴 ] 교수

**대격 관계절(ORC)**: 핵어명사가 관계절 내에서 목적어 역할 → 공백이 목적어 위치
- 구조: [ 주어가 _i V-ㄴ ] 핵어명사_i
- 예: [ 학생이 _i 쓴 ] 논문

**처리 비대칭성(asymmetry)**:
영어 등 핵어 전치(head-initial) 언어에서는 SRC가 ORC보다 처리가 쉽다는 것이 강건한 발견이다. 그러나 한국어 같은 핵어 후치 언어에서는 결과가 혼재한다.

- DLT(Dependency Locality Theory, Gibson 2000) 예측: 한국어 ORC에서 공백과 핵어명사 사이에 개재하는 새 담화지시체가 없으므로, ORC 이점이 가능
- Surprisal 이론: 조건부 확률에 의존 — 한국어 코퍼스에서 SRC/ORC 빈도에 따라 방향이 달라질 수 있음
- Cue-based retrieval: 관계절 동사에서 주어/목적어를 인출할 때 유사성 간섭(similarity-based interference)이 핵심. 두 명사구가 유사할수록 간섭 증가

이 실험의 핵심 질문은 **LLM의 surprisal이 이 비대칭성을 어느 방향으로 보이는지, 인간 데이터와 일치하는지**이다.

### 자극 설계 제안

- 2(관계절 유형: SRC vs ORC) × 1 설계, 조건당 20문항, 총 40 실험 문항
- 최소 대립쌍(minimal pair): 동일 어휘를 사용하되 주격/대격만 교차

#### 자극 구성 세부 규칙
1. **명사 유생성(animacy) 통제**: SRC/ORC 모두 관계절 내 두 명사를 유정(animate) 명사로 통일. 유정-유정 조합이 간섭 효과를 극대화하여 이론적으로 더 흥미로운 조건.
2. **어절 수 통제**: 모든 문항에서 관계절 포함 총 어절 수를 6으로 고정.
3. **관계절 동사 통일**: 같은 문항 쌍 내에서 관계절 동사는 동일.
4. **주절 동사 자동사**: 핵어명사 이후 구조를 단순화하여 주절 처리 차이 최소화. (주의: ORC에서는 주절 동사가 타동사가 될 수 있으므로, 주절 동사 유형도 통제 항목에 포함)
5. **어휘 빈도**: 세종 코퍼스 기준 상위 5,000어 내의 명사·동사만 사용.
6. **존대법**: 전체 자극을 해라체(반말 서술형)로 통일.

#### 관심 영역(critical region) 지정
- **RC_verb** (관계절 동사): 핵심 측정 영역. 관계절 유형에 따른 surprisal 차이의 주된 발현 지점.
- **head** (핵어명사+조사): 관계절-핵어 통합이 일어나는 지점. 두 번째 핵심 영역.
- **main_verb** (주절 동사): spillover 효과 확인용.

### 교란변인 목록

| 교란변인 | 위험 | 통제 방법 |
|----------|------|----------|
| 어휘 빈도 불균형 | 조건 간 고빈도/저빈도 편향 | 세종 코퍼스 빈도표에서 조건별 평균 log빈도 맞춤 (paired t-test로 확인) |
| 어절 길이(음절 수) | 긴 어절 = 높은 surprisal | 각 영역별 음절 수를 조건 간 동일 또는 ±1 음절 내 |
| 의미적 그럴듯함(plausibility) | 어색한 문장 = 높은 surprisal (구조 효과 혼재) | 별도 norming: 5명에게 자연스러움 7점 척도 판단, 조건 간 평균 5.0 이상 |
| 구문 빈도(construction frequency) | 한국어 코퍼스에서 SRC가 ORC보다 훨씬 빈번 → 모델이 SRC를 더 예측 | 통제 불가(변인 자체가 관심 대상일 수 있음). 해석 시 명시 |
| 관계절-주절 모호성 | 관계절 시작 시점의 모호성이 조건마다 다를 수 있음 | 시간부사(어제/최근/아까/오늘/그때)로 문장 시작 → 주절 기대 설정, 관계절 내부 명사에서 모호성 발생 통제 |
| 조사-격표지 정보량 | -이/가(주격) vs -을/를(대격)의 unigram 빈도 차이 | 조사 자체의 surprisal을 별도 분석, 조사 제외 영역(동사)에서의 효과를 주 분석으로 |
| 명사 유생성 | 유정/무정에 따라 구조 기대 변화 | 유정-유정으로 통일 (위 참조) |
| 주절 동사 유형 | 자동사/타동사에 따른 논항 기대 차이 | SRC: 자동사, ORC: 타동사로 자연스럽게 대응. 불가피한 차이이므로 해석 시 언급 |

### 이론적 예측

| 이론 | SRC vs ORC 예측 (관계절 동사 영역) | 근거 |
|------|-------------------------------|------|
| DLT (Gibson 2000) | ORC ≤ SRC (한국어) | 한국어 ORC에서 filler-gap 거리가 짧아 통합 비용 낮음 |
| Surprisal (Hale/Levy) | 코퍼스 빈도 의존 | 한국어 코퍼스에서 SRC 빈도 > ORC 빈도 → ORC surprisal 높을 가능성 |
| Cue-based retrieval (Lewis & Vasishth) | 유정-유정 조건에서 ORC 불리 | 두 유정 명사 간 간섭으로 ORC에서 목적어 인출 오류 증가 |
| Experience-based (Wells et al. 2009) | SRC 이점 | 코퍼스 빈도에서 SRC가 압도적으로 많아 처리에 유리 |

LLM 예측: LLM은 코퍼스 기반 통계를 직접 학습하므로, **surprisal 이론의 예측과 가장 가까울 가능성**이 높다. 즉, 한국어 코퍼스에서 SRC 빈도가 높다면 ORC에서 더 높은 surprisal을 보일 것이다.

### 주의사항

1. **SRC/ORC 최소 대립쌍의 완전성 한계**: 한국어 관계절에서 SRC와 ORC를 완벽하게 최소 대립쌍으로 만들기 어렵다. ORC에서는 관계절 내에 명시적 주어가 필요하고, SRC에서는 필요하지 않을 수 있다. 위 설계에서는 SRC에 부사어구를 넣어 어절 수를 맞췄지만, 이것이 완벽한 통제인지는 논의 필요.

2. **영형 주어 문제**: 한국어에서는 관계절 내 주어를 생략할 수 있다. SRC에서는 주어가 공백이므로 자연스럽지만, ORC에서 주어를 생략하면 SRC로 오해석될 수 있다. → ORC에서는 관계절 내 주어를 반드시 명시.

3. **관계절 경계 모호성**: 한국어에는 관계절 도입 표지(that/which 같은 관계대명사)가 없다. 관계절의 시작이 명시되지 않으므로, 어디서 관계절이 시작되는지에 대한 파싱 모호성이 존재. 이 모호성 자체가 surprisal에 기여할 수 있으며, 조건 간 차등적 영향을 줄 수 있다.

4. **토크나이저 의존성**: LLM의 토크나이저가 한국어 어절/형태소를 어떻게 분절하느냐에 따라 surprisal 영역 대응이 달라진다. 분석 시 subword → 어절 집계 방법을 명확히 정의해야 한다.

5. **인간 데이터 비교 시**: 인간 읽기시간 데이터가 이미 존재하는 경우(예: Kwon et al. 2010; Yun et al. 2015 등 한국어 관계절 SPR 연구), 해당 연구의 자극 설계와 가능한 한 일치시키면 비교 타당성이 높아진다. 새 자극을 만들 경우 인간 데이터 수집도 필요할 수 있다.

1. 필러 문항 예시 3–5개 추가하면 실무 담당이 전체 자극 세트를 완성하기 쉬움
