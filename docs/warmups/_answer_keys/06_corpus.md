# 06 채점표 (stimuli.csv에서 계산)

조건별 평균·표준편차:

```
          log_freq        n_syll        n_subword       
              mean    std   mean    std      mean    std
condition                                               
A            3.287  0.453  2.525  0.640      2.10  0.810
B            3.293  0.512  3.475  0.987      3.05  1.085
```

심어 둔 문제 4가지:
1. 음절 수 불일치: B − A 평균 0.950음절, 대응 t(39) = 5.11
2. 서브워드 수도 따라서 불일치: B − A 평균 0.950, 대응 t(39) = 5.21
3. 목표어 중복 2건: 7번 문항 B가 같은 문항 A와 같은 T007a, 23번 문항 B가 12번 문항 A와 같은 T012a
4. 결측 1건: 31번 문항 A의 log_freq

로그 빈도는 맞춰져 있음: B − A 평균 0.015, 대응 t(38) = 0.14 (결측 문항 제외 39쌍)

합격: 1·3·4를 수치와 문항 번호로 지적(2는 가점). 빈도를 불일치로 잘못 지적하면 감점. 표의 수치가 위와 소수 둘째 자리까지 일치.
