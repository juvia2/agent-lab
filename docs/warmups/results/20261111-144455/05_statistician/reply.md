## 결론

**권장 N = 90명** (dz = 0.3, 양측 α = .05, 검정력 .80). 탈락을 고려하지 않은 수치입니다.

| 기준 | 최소 N | 근거 (`power_curve_dz03.csv`) |
|---|---|---|
| 시뮬레이션 검정력 ≥ .80 | 89 | power_sim = 0.8005 |
| 해석해(비중심 t) ≥ .80 | 90 | power_analytic = 0.8038 |
| 시뮬레이션 95% CI 하한 ≥ .80 (보수적) | 91 | ci95_lo = 0.8060 |

시뮬레이션만 보면 89가 가장 먼저 .80을 넘습니다. 하지만 바로 다음 N = 90에서는 0.7968로 다시 내려갑니다. 몬테카를로 오차(SE ≈ 0.003) 때문에 경계 부근에서 곡선이 단조롭지 않은 것입니다. 그래서 89를 그대로 채택하지 않고, 해석해와 일치하는 **90**을 권장합니다. 오차까지 보수적으로 반영하려면 **91**을 쓰면 됩니다.

## 가정

- 주효과 A의 검정: 참가자별 차이점수 [mean(A1B1, A1B2) − mean(A2B1, A2B2)]에 대한 일표본(대응) t 검정을 씁니다. 이는 2×2 RM-ANOVA의 A 주효과 F(1, N−1)과 같습니다(F = t²).
- 차이점수는 Normal(0.3, 1)을 따른다고 가정했습니다. 효과크기 dz는 차이점수 평균을 차이점수 SD로 나눈 값으로 정의합니다.
- 결측과 탈락은 없고, 참가자는 서로 독립이라고 가정했습니다.
- 반복 수: N = 70–110 각각에 대해 20,000회입니다. 시드는 20261111입니다.
- 실행 환경: python 3.12.16, numpy 2.5.4, scipy 1.18.1, pandas 3.1.1.

## 검산: 셀 수준 생성 (`power_cells_check.csv`)

4개 셀을 복합대칭 구조(셀 간 상관 ρ = 0.3, 0.5, 0.7)로 생성하고, 셀별 평균 차이는 dz가 0.3이 되도록 맞췄습니다. B 주효과와 A×B 상호작용은 0으로 두었습니다. N = 90에서의 검정력은 다음과 같습니다.

| ρ | 시뮬레이션 검정력 | 해석해 |
|---|---|---|
| 0.3 | 0.8048 | 0.8038 |
| 0.5 | 0.7986 | 0.8038 |
| 0.7 | 0.8026 | 0.8038 |

세 경우 모두 해석해와 MC 오차 범위 안에서 일치합니다. 즉 dz를 기준으로 효과를 정하면 셀 간 상관은 필요한 N에 영향을 주지 않습니다.

## 주의점

- **효과크기의 출처를 확인해야 합니다.** 선행연구가 보고한 값이 dz가 아니라 d_av나 셀 SD 기준 d라면, dz = d / √(2(1−ρ))로 환산해야 합니다. 이때 ρ에 따라 필요한 N이 크게 달라집니다. 예를 들어 ρ = 0.5이면 d = dz이고, ρ가 이보다 높으면 dz가 커져서 필요한 N이 줄어듭니다.
- **문항 수준 분석은 다릅니다.** 문항이 여러 개이고 혼합효과모형(참가자와 문항 랜덤효과)으로 분석할 계획이라면, 이 계산은 그대로 적용되지 않습니다. 그 경우에는 문항 수와 분산 성분을 가정한 별도 시뮬레이션이 필요합니다.
- **탈락을 반영해야 합니다.** 예상 탈락률을 r이라 하면 모집 인원은 90 / (1 − r)로 잡습니다.
